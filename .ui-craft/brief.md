# Product purpose

CompassNCrew presents its services and software work through a premium agency site with an optional interactive 3D portfolio journey.

# Primary user

A business owner or product lead evaluating a software partner on desktop or mobile, often in a short first-visit session.

# Principles

1. **The work is the proof.** Interactive visuals must lead to real, legible project information.
2. **Exploration is optional.** Every 3D interaction needs an automatic path and an accessible recovery route.
3. **Never strand the visitor.** Back and Home remain obvious at every point in the journey.
4. **Premium means controlled.** Use the established charcoal, cream, and amber system with restrained motion and crisp hierarchy.

# Success metric

A visitor can open the software portfolio from the homepage, view projects automatically or drive manually, and return to the referring page or homepage without confusion.

# Out of scope

- Does not replace the existing service landing page taxonomy.
- Does not introduce a second website-wide navigation system.
- Does not add unverified client claims or finished project imagery.
- Does not require WebGL to access the project index.

# Learned constraints

- **2026-08-09** — Mobile onboarding, driving controls, and project details must occupy distinct interface states. *Why:* overlapping controls made the first visit difficult to read and operate on narrow screens.

- **2026-08-09** — Portfolio showcases pause for three seconds in automatic mode. *Why:* five seconds felt too slow across a 20-project journey.
- **2026-08-09** — The 3D system belongs inside the CompassNCrew project and must provide both Back and Home recovery actions. *Why:* the journey is part of the business-site funnel, not a disconnected microsite.
